# `scale_forecasting` Package (`src/scale_forecasting/`)

`scale_forecasting` is structured around **one capability per file** and a strict separation between **pure planning/math** and **cloud I/O**. Every execution surface — local Python, Dataproc Spark (Serverless and GCE Clusters), Ray on Vertex AI, Vertex AI `CustomJob`, Compute Engine (`gce`), Google Kubernetes Engine (`gke`), and Cloud Composer (Airflow) — imports this exact package and runs the same per-series unit of work ([`worker.run_cell`](./worker.py)).

The package root ([`__init__.py`](./__init__.py)) uses a PEP 562 lazy `__getattr__` loader so importing `scale_forecasting` never pulls in heavy optional dependencies (`pyspark`, `ray`, `torch`, `neuralprophet`) until the specific module or model is requested.

### 2. Core Forecasting & Evaluation Pipeline
- **[`worker.py`](./worker.py):** Defines `run_cell(series, model_name, cfg) -> CellResult` — the single per-series unit of work shared across local, Spark, Ray, Vertex `CustomJob`, GCE, and GKE execution, plus `run_panel_model` for cross-series global/hybrid/`@similarity_global` models.
- **[`features.py`](./features.py), [`simplex.py`](./simplex.py), [`cold_start.py`](./cold_start.py) & [`similarity.py`](./similarity.py):** Builds historical and future exogenous design matrices (target transforms `log1p`/`boxcox` plus Aitchison compositional `clr`/`ilr` log-ratio transforms with multiplicative zero replacement and Helmert contrast matrices, country holidays, moving-holiday lead/lag windows, Fourier terms, binary-segmentation level shifts, `static_covariates`, `future_covariates`, `past_covariates`, `exog`, `exog_lags`, composable `@<tag>` model variant resolution, cold-start / NPI analog donor transfer `cold_start_transfer_df`, `match_cold_start_donors`, `fit_bass_diffusion`, `fit_weibull_lifecycle`, and 7-lens time-series similarity, Takens phase-space / Kuramoto spectral embeddings, spectral clustering, lead-lag discovery, and launch-prefix kinematic matching `compute_similarity_matrix`, `cluster_by_similarity_df`, `find_similar_series_df`, `match_cold_start_launch_prefix_df`, `plot_similarity_map`).
- **[`monotonicity.py`](./monotonicity.py):** Economic sign constraint inference (`infer_monotonic_constraints`), config/variant merging (`resolve_monotonic_constraints`), feature-aligned constraint vector construction (`build_monotonic_constraint_vector`), and `scipy.optimize.lsq_linear` bounded Ridge regression (`fit_sign_constrained_ridge`) for `@monotone` model variants (`lightgbm`, `xgboost`, `catboost`, `regression_lags` / `ridge_lags`).
- **[`holiday_window.py`](./holiday_window.py):** Multi-day moving-holiday lead/lag window configuration (`HolidayWindowConfig`) and deterministic pre-holiday build-up (`pre_holiday_window`, `days_to_next_holiday`) and post-holiday slump (`post_holiday_window`, `days_since_prev_holiday`, `holiday_offset_days`) ramp generators (`build_holiday_window_features`).
- **[`backtest.py`](./backtest.py):** Rolling-origin cross-validation (`expanding`, `sliding`, `expanding_frozen`, `expanding_stale`), short-series policies, fold geometry resolution, and metric panel scoring.
- **[`calibration.py`](./calibration.py), [`aci.py`](./aci.py) & [`copula.py`](./copula.py):** Out-of-fold conformal prediction-interval calibration, online Adaptive Conformal Inference (`compute_aci_trajectory`, `compute_aci_df`, `calibrate_intervals_aci`, `plot_aci`) with horizon-delay buffering and EWMA volatility normalization (`aci_normalized`), joint cross-series & cross-horizon Gaussian and Student-$t$ copula trajectory simulation (`sample_trajectories`, `plot_trajectories`), and portfolio VaR / CVaR tail-risk analytics (`compute_tail_risk`).
- **[`reconciliation.py`](./reconciliation.py) & [`temporal_reconciliation.py`](./temporal_reconciliation.py):** Hyndman FPP3 cross-sectional hierarchical and grouped forecast reconciliation (`bottom_up`, `top_down`, `middle_out`, `ols`, `wls_struct`, `wls_var`, `mint_shrink`, `mint_nonneg`), Athanasopoulos et al. (2017) Temporal Hierarchies (`THieF` via `reconcile_temporal_forecasts` and `reconcile_series_temporal`), and Kourentzes & Athanasopoulos (2019) Simultaneous Cross-Temporal Reconciliation (`cross_temporal_mint`).
- **[`hpo.py`](./hpo.py):** Optuna hyperparameter optimization (`fleetwide` sampled pre-pass or `per_series` in-worker studies).
- **[`ensembler.py`](./ensembler.py) & [`ensemble_run.py`](./ensemble_run.py):** Pure mathematical blending (`mean`, `median`, `inverse_error`, `nnls`, `ridge`, `xgb`) and the registry-backed ensemble job runner (including cross-run ensembling).
- **[`seasonality.py`](./seasonality.py):** Maps pandas frequency codes (`D`, `W`, `MS`, `h`, etc.) to seasonal periods and Fourier harmonic counts.

The extras seam lives here too: `EXTRA_MODULES` maps each cloud-facing extra (`gcp`, `notebook`, `spark`, `ray`, `submit`, `models-automl`) to the import names that prove it is installed, `is_importable()` probes one module without importing it, and `require_extra(extra, purpose=...)` raises `MissingExtraError` with the exact `pip install "scale-forecasting[<extra>]"` / `uv sync --extra <extra>` line — called once at every entry point that needs the extra (`main.run`, the submitters, `registry.ops`, plotting) so a core-only install fails with guidance instead of a `ModuleNotFoundError` from deep inside a client library. Also the package's logging seam: `get_logger()` (named loggers that attach nothing and propagate — the package logger carries one `NullHandler`, so Airflow, a notebook, or any host routes the records with its own configuration) and `configure_cli_logging()` (the root handler every `python -m scale_forecasting.<module>` entry point installs unless the host already has one; `SF_LOG_LEVEL` sets the level).
- **[`py.typed`](./py.typed):** PEP 561 marker shipped in the wheel. It tells downstream type-checkers that the package's annotations are authoritative, which is why `mypy src/scale_forecasting` is a CI gate (zero errors) and not a suggestion: every public signature is a promise someone else's checker will hold us to.
