# `scale_forecasting.mcp`

Built-in, zero-extra JSON-RPC 2.0 Model Context Protocol (MCP) server over `stdio` (`python -m scale_forecasting.mcp`) exposing 7 resources and 9 tools across offline model benchmarking, `RunConfig` validation, multi-family DAG planning, Airflow DAG emission, and live BigQuery registry inspection/review/repair.

See the [AI Agents, Portable Skills & Built-in MCP Server](../agent_and_mcp_guide.md) guide for client configuration and tool examples.
